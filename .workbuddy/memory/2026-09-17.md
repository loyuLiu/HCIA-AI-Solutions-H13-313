## 新增「课程总纲」页面（侧栏入口 + 展示总纲.png）

用户要求：左侧栏新增一个「课程总纲」，点开展示 `总纲.png`。

### 关键点：图片必须放进 hcia-platform 目录内
`总纲.png` 原本在**工作区顶层**，但 `server.js` 的 `serveStatic` 以 `ROOT = hcia-platform` 为根，
且显式 403 拦截 `data/` 与 `node_modules/` —— 上层目录的文件根本访问不到。
解决：复制到 `hcia-platform/assets/img/总纲.png`（1.5 MB，**保留中文原名**，方便用户直接替换图片）。
实测 `http://127.0.0.1:8787/assets/img/%E6%80%BB%E7%BA%B2.png` → 200。
（`serveStatic` 用 `decodeURIComponent(url.pathname)`，中文名 URL 编码后可正常命中，无需改英文名。）

### 改动
- `index.html`：nav 末尾加 `<a class="nav-item" data-view="outline"><i class="ic ic-outline"></i>课程总纲</a>`
  （已有通用 `$$(".nav-item").onclick` 绑定，无需新增事件）
- `app.js`：
  - `render()` 加分支 `else if (view === "outline") c.innerHTML = viewOutline();`
  - `navTitle()` 加 `outline: "课程总纲"`
  - 新增 `OUTLINE_SRC`（对文件名做 `encodeURIComponent`）、`outlineScale`（默认 100）、
    `applyOutlineScale()`、`viewOutline()`
  - `action()` 加 `outline-zoom`（±25%，钳制 50~300%）/ `outline-fit`（回 100%）
  - `bindDynamic()` 给 `#outlineImg` 绑 `onerror` → 隐藏图片 + 显示提示文字
- `style.css`：新增 `.ic-outline`（表格/大纲图标，mask-image 内联 SVG）、
  `.outline-bar` / `.outline-wrap` / `.outline-img`（居中、圆角、阴影、宽度过渡）；≤900px 适配

### 踩坑
- **缩放别用整页 `render()`**：`Cache-Control: no-cache` 且服务器不处理 304，重渲染会让 1.5 MB 图片
  重新下载并闪烁。改为只改 `img.style.width` + 更新比例文字。
- **测试断言踩到 URL 编码**：`img.getAttribute("src")` 拿到的是 `总纲.png` 的百分号编码形式，
  直接 `indexOf("总纲.png")` 必然失败。断言里要 `decodeURIComponent()` 后再比（同理适用于 `href`）。
